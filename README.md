# Personal Dotfiles
Editor: Neovim

| Keybind | Function |
| -------------- | --------------- |
| space | leader key |
| <leader>pk | Search keymaps |
Shell: zsh

| Keybind | Function |
| -------------- | --------------- |
| C-r | Past Commands |
| C-t | File paths |
| A-c | cd using fzf |
Terminal Multiplexer: tmux

| Keybind | Function |
| -------------- | --------------- |
| C-space | prefix |
| C-left/right/up/down | Navigate through tmux panes |
## Requirements
For zsh:
    - Powerlevel10k
    - Oh My Zsh
    - git
    - zsh-autosuggestions
    - zsh-syntax-highlighting
    - zsh-vi-mode
    - fzf-tab
    - Ripgrep
For tmux:
    - tmux-plugin-manager
    - tmux-plugins/tpm
    - christoomey/vim-tmux-navigator
    - egel/tmux-gruvbox
    - vim-tmux-navigator (nvim)
For nvim:
    - Neovim v0.12>=
    - nvim-treesitter
    - Mason
    - nvim-lspconfig
    - efmls-configs-nvim
        - efm-langserver (mason)
    - mini.nvim
    - fzf-lua
    - blink.cmp
    - Luasnip
    - Friendly-snippet
